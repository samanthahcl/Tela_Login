# Tela de Login

Projeto simples de uma tela de login feita com **HTML e CSS**.

## Tecnologias

* HTML
* CSS
* Boxicons
* Google Fonts

## Sobre

A tela possui:

* Campo de usuário
* Campo de senha
* Opção "Remember me"
* Link "Forgot password?"
* Botão de Login
* Link para cadastro

O CSS também foi usado para adicionar um **fundo com imagem**, efeito de **transparência e desfoque**, bordas arredondadas e deixar a tela centralizada.

## Arquivos

```text
index.html
style.css
README.md
```

## Como executar

Basta abrir o arquivo `index.html` no navegador.
